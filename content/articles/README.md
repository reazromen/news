# Article source directory

One Markdown file per published article. Filenames should match the slug. Only reviewed articles with `status: "published"` are rendered. Do not put drafts, feed snapshots, credentials, or full copyrighted source articles here.

Example front matter:

```yaml
---
title: "প্রতিবেদনের শিরোনাম"
slug: "unique-ascii-slug"
date: "2026-10-16T10:00:00+06:00"
updated: "2026-10-16T10:00:00+06:00"
source_name: "তথ্যসূত্রের নাম"
source_url: "https://example.com/source-story"
summary: "প্রতিবেদনের সংক্ষিপ্তসার।"
category: "বাংলাদেশ"
status: "published"
---

এখানে নিজস্ব প্রতিবেদন লিখুন। উৎসের তথ্য যাচাই করে লিখতে হবে; একটি উৎসের লেখা বাক্য ধরে ধরে পুনর্লিখন করা যাবে না।
```
